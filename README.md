# Hadir Acara

[Demo](https://sukmalistyoo.github.io/hadir-acara/)

| Halaman | Yang bisa dicoba |
| --- | --- |
| Rapat dinas | Isi kegiatan, tambahkan peserta dan tanda tangan, lalu simpan lembar hadir di browser. QR Rapat membuka formulir lokal di perangkat pemindai. |
| Materi rapat | Mulai sesi dan bagikan QR Materi. HP peserta mengikuti slide operator selama sesi aktif. |
| Wedding | Bagikan undangan atau QR Buku Tamu dan lihat rekap kedatangan. |
| Undangan tamu | Buka tautan undangan dari panitia untuk mengonfirmasi jumlah tamu yang hadir atau berhalangan. |
| Buku tamu | Pindai QR Buku Tamu di lokasi, isi nama dan alamat, lalu tanda tangani kehadiran. |

Gunakan data fiktif. Sesi presentasi berlaku satu jam. Acara wedding demo berlaku 24 jam.
